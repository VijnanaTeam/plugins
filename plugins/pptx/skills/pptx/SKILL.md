# PowerPoint 演示文稿

## 工作原则

- 先明确受众、演示时长、场合、目标和是否必须沿用现有模板。
- 一页表达一个主要观点；标题应传达结论，不只写主题名称。
- 使用母版、版式和对齐系统保持一致，不逐页堆叠临时样式。
- 图表必须标出单位、时间范围和数据来源；不捏造数据或引用。
- 修改现有演示时保留未要求改变的母版、品牌元素、动画、备注和隐藏页。

## 执行流程

1. 检查可用的演示文稿读取、编辑和渲染能力；缺少必要能力时明确报错。
2. 建立故事线：开场、背景、关键发现或方案、证据、结论和下一步。
3. 创建或编辑页面，控制文本密度，保证字号、对比度、留白和图片比例。
4. 将细节移入讲者备注；页面正文只保留现场需要看到的信息。
5. 保存为真正的 `.pptx` 文件。
6. 渲染所有页面并检查文字溢出、元素重叠、图片拉伸、图表可读性、页码和模板一致性。

## 交付

说明输出文件、页数、故事线和任何需要用户补充的数据、图片或品牌素材。
