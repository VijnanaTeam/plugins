# PDF

## 工作原则

- 先判断 PDF 是文本型、扫描型、混合型还是带表单字段，并确认是否有密码或权限限制。
- 不把 OCR 结果当作绝对准确；姓名、金额、日期、编号和表格必须重点核对。
- 保持原始页面顺序、尺寸、方向和可搜索性，除非用户明确要求改变。
- 对签名、加密或受限制文件，不绕过权限；需要密码时直接向用户说明。

## 执行流程

1. 检查可用的 PDF 解析、编辑、OCR、表单和渲染能力；缺少必要能力时明确报错。
2. 读取页数、页面尺寸、文本层、书签、表单字段和加密状态。
3. 按任务处理：
   - 提取：保留页码来源，表格优先输出结构化数据。
   - OCR：逐页识别，并标记低置信度内容。
   - 合并/拆分/旋转：先列出目标页序，避免页码偏移。
   - 填表：只填写用户给出的值，不猜测空字段。
   - 创建：使用真实 PDF 生成能力，不用图片改扩展名。
4. 保存到新文件；除非用户明确要求，不覆盖原文件。
5. 渲染全部页面进行视觉检查，确认文字、表格、图片、表单值和页码没有裁切或错位。

## 交付

说明生成或修改的文件、处理页范围、是否执行 OCR，以及需要用户复核的识别结果。
