# 企业微信

企业微信的所有操作都通过官方命令行工具 **`wecom-cli`** 完成。它自带成套官方技能文档,覆盖消息、文档、智能表格、日历、会议、待办、通讯录、微盘、邮件等。

## 怎么用(先查技能,再动手)

**不要凭记忆猜命令和参数**,按官方技能走:

```bash
wecom-cli --version         # 确认可用(首次执行会自动安装,需稍等)
wecom-cli --help            # 顶层能力总览
wecom-cli <domain> --help   # 某个业务域的命令与参数
```

官方技能文档中通常有一份**公共前置说明**(讲清检查顺序与通用约束),先读它,再读对应业务技能,然后执行。

## 授权(仅需一次)

```bash
wecom-cli auth show --status    # 检查是否已授权
```

显示未授权时:

```bash
wecom-cli auth login            # 输出授权链接与二维码,并等待扫码
```

把**授权链接原样交给用户**,请其用企业微信扫码确认(链接有效期约 5 分钟,过期就重新执行)。
**授权成功后本工作环境的所有部门通用,不需要重复授权。** 授权数据由平台放在共享目录,你不需要也不要去改它。

## 约定

- 所有操作以**用户本人**的企业微信身份进行,受其自身权限与可见范围约束。
- 写操作(发消息、改删文档、建改会议日程、传文件等)执行前,先向用户确认目标与内容。
- 命令输出多为结构化数据,可直接解析后再做下一步;需要落地的文件用 CLI 提供的下载命令,不要手工拼 API。
- 遇到权限或授权错误:把 CLI 给出的原始提示与链接如实转达用户,不要反复重试或绕路。
- 不要把内部 ID 类字段直接展示给用户,用名称等可读信息表述。
