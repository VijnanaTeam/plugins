# 企业微信

企业微信的所有操作都通过官方命令行工具 **`wecom-cli`** 完成。

## 怎么用(先查帮助,再动手)

**不要凭记忆猜命令和参数**:

```bash
wecom-cli --help            # 顶层能力总览
wecom-cli help <domain>     # 某个业务域的命令与参数
```

首次执行会自动安装 CLI(需等待片刻)。

业务域:`message` 消息、`chat` 会话、`doc` 文档、`sheet` 表格、`smartsheet` 智能表格、
`smartpage` 智能主页、`disk` 微盘、`calendar` 日历、`meeting` 会议、`todo` 待办、
`contact` 通讯录、`mail` 邮件、`media` 媒体文件。

## 授权

本部门首次使用要授权一次,之后一直有效。命令是固定的两条,**照抄**:

```bash
wecom-cli auth show                                # 先看状态(未授权会显示 Status: unauthorized)
wecom-cli auth init --noninteractive --no-browser  # 未授权才执行
```

- **不存在 `auth login`**,企微这里是 `auth init`。
- **`--noninteractive` 与 `--no-browser` 都要带**。这里是无头容器:没有可交互的终端,也没有
  浏览器可打开;不带这两个参数会卡在交互选择上或试图拉起浏览器。
- 授权数据由平台统一管理,不要手动改动。

命令会打印一个**扫码链接**和一大片 ASCII 二维码。**只把链接交给用户**(单独一行、纯 URL),
不要把 ASCII 二维码复制进回复 —— 它在聊天界面里会糊成乱码。链接有时效,过期就重新执行。

> **转述链接的硬性要求**:给用户的链接必须是**干净可点的纯 URL** —— 逐字复制 `http(s)://`
> 开头到第一个空白为止的部分,**去掉紧邻的 `*`、反引号、括号等装饰字符**,也不要自己再包一层
> 加粗。链接里多一个字符就会打不开。

## 约定

- **企微这里是「机器人」身份,不是用户本人身份**(与飞书/钉钉不同)。能做什么取决于该机器人
  被授予的范围,遇到做不了的事先说明这一点,不要让用户以为是自己账号权限不足。
- 写操作(发消息、改删文档、建改会议日程、传文件等)执行前,先向用户确认目标与内容。
- 命令输出多为结构化数据,可直接解析后再做下一步;需要落地的文件用 CLI 提供的下载命令,不要手工拼 API。
- 遇到权限或授权错误:把 CLI 给出的原始提示与链接如实转达用户,不要反复重试或绕路。
- 不要把内部 ID 类字段直接展示给用户,用名称等可读信息表述。
