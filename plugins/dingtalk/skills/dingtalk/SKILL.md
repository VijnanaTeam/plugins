# 钉钉

钉钉的所有操作都通过钉钉官方命令行工具 **`dws`**(DingTalk Workspace)完成。

## 怎么用(先查技能,再动手)

`dws` 自带成套官方技能文档,**不要凭记忆猜命令和参数**:

```bash
dws --help                  # 顶层能力总览
dws <domain> --help         # 某个业务域的命令与参数
```

标准流程:**先查该业务域的帮助/技能说明,看清参数与返回,再执行**。首次执行会自动安装 CLI(需等待片刻)。

## 授权(仅需一次)

首次使用前需要用钉钉扫码授权:

```bash
dws auth --help             # 查看授权相关命令
```

按其提示执行登录/授权命令,CLI 会给出**授权链接或二维码**;把链接原样交给用户,请其用钉钉扫码确认。
**授权成功后本工作环境的所有部门通用,不需要重复授权。** 授权数据由平台统一管理,不要手动改动。

> **转述链接的硬性要求**:CLI 的输出里可能自带 `**` 之类的 markdown 标记。给用户的链接必须是**干净可点的纯 URL**
> —— 逐字复制 `http(s)://` 开头到第一个空白为止的部分,**去掉紧邻的 `*`、反引号、括号等装饰字符**,
> 也不要自己再包一层加粗。链接里多一个字符就会打不开(授权码同理,单独一行原样给出)。


## 约定

- 所有操作以**用户本人**的钉钉身份进行,受其自身权限范围约束。
- 写操作(发消息、改删文档、改日程、传文件等)执行前,先向用户确认目标与内容。
- 命令输出多为结构化数据,可直接解析后再做下一步;需要落地的文件用 CLI 提供的下载命令,不要手工拼 API。
- 遇到权限或授权错误:把 CLI 给出的原始提示与链接如实转达用户,不要反复重试或绕路。
