# 飞书(Feishu)

连接飞书后,你会获得一批以飞书身份操作的工具(工具名形如 `docx_*`、`bitable_*`、`im_*`、
`drive_*`、`wiki_*`、`sheets_*`、`task_*`、`calendar_*` 等),直接调用即可,无需再处理鉴权——
凭据由平台按当前用户注入。

## 常用场景
- **云文档**:`docx_*` 读取/创建/编辑文档;`drive_*` 找文件、管权限;`wiki_*` 检索知识库节点。
- **多维表格**:`bitable_*` 增删改查记录、表、字段。
- **消息与群**:`im_*` 列群、查群成员、收发消息。
- **表格/日历/任务**:`sheets_*` / `calendar_*` / `task_*`。

## 约定
- 需要先在「插件中心 → 飞书 → 连接」完成授权;未连接时相关工具不可用,请提示用户去连接。
- 所有操作以**用户本人**的飞书身份进行,遵守其权限范围。
- 写操作(发消息、改文档、删记录等)前先向用户确认目标与内容。
