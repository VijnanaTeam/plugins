# Excel 工作簿

## 工作原则

- 先识别工作表、表头、数据类型、公式、命名区域、筛选、隐藏行列和合并单元格。
- 原始数据、计算逻辑和展示层尽量分开；不要把应计算的结果硬编码成数值。
- 公式引用要可复制、可审计；需要固定的行列使用明确的绝对引用。
- 保留前导零、日期、货币、百分比和时区语义，避免自动类型转换破坏数据。
- 不臆造缺失数据；清洗规则和删除记录数量必须可说明。

## 执行流程

1. 检查可用的工作簿读写、公式计算、图表和渲染能力；缺少必要能力时明确报错。
2. 读取工作簿结构和关键区域，确认任务涉及的工作表与输出格式。
3. 执行清洗、计算或重构：
   - 使用稳定表头和统一数据类型。
   - 检查除零、空值、错误值、重复记录和断裂引用。
   - 图表使用清楚标题、单位、图例和合适的数据范围。
4. 保存为真正的 `.xlsx`、`.csv` 或 `.tsv` 文件；不得只改扩展名。
5. 重新打开并核对公式、关键汇总、筛选范围、冻结窗格、打印区域和可读性。

## 交付

说明输出文件、工作表变化、主要公式或清洗规则，以及任何需要用户确认的异常数据。
